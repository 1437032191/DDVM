# DDVM: A Mamba-Based Method for Building Extraction from High-Resolution Remote Sensing Imagery
High-resolution remote sensing imagery exhibits significant differences in information distribution between buildings and background regions. Conventional fixed downsampling on regular grids struggles to preserve important spatial information while maintaining computational efficiency. To address this issue, we propose a Dynamic Downsampling Visual Mamba (DDVM) model for building extraction from high-resolution remote sensing imagery. First, a content-aware dynamic downsampling strategy is designed to adaptively select sampling locations based on feature importance and spatial constraints. This allows more computational resources to be allocated to information-rich regions, such as buildings and their surroundings, while reducing redundant computation in background regions. Second, to handle the irregularly distributed sparse points generated by dynamic downsampling, we introduce a Hilbert-curve-based irregular patch partitioning strategy. It combines spatial serialization with equal-length grouping to balance the number of tokens across patches while preserving spatial adjacency as much as possible. Furthermore, we develop a Point-based Visual Sequence Sampling Block (PVSS Block) tailored to sparse point features. By combining PointConv-based local geometric aggregation with Hilbert-based cross-scanning, this block captures local spatial structures and models long-range contextual dependencies in irregular spatial representations. Experimental results on different building extraction datasets demonstrate that DDVM outperforms the compared methods in both overall segmentation accuracy and boundary extraction quality while effectively controlling computational cost, achieving a favorable balance between building extraction accuracy and computational efficiency.
